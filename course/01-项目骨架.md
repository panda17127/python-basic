# 第 1 课:项目骨架

## 目标

理解一个最小 FastAPI 项目里**每个文件为什么存在**。

## 结构与职责

```
lianxi/
├── app/
│   ├── __init__.py   ← 告诉 Python "app 是一个包"
│   └── main.py       ← 应用入口:创建 FastAPI 实例 + 定义路由
├── requirements.txt  ← 依赖清单,别人 pip install -r 即可复现环境
├── .gitignore        ← 告诉 git 哪些文件不纳入版本管理(__pycache__、.venv、.env)
└── README.md         ← 写给人看的说明书
```

## 最小可运行代码

```python
# app/main.py
from fastapi import FastAPI

app = FastAPI(title="good-finds-server", version="1.3.0")

@app.get("/api/health")
def health():
    return {"code": 0, "msg": "ok", "data": {"service": "good-finds-server", "version": "1.3.0"}}
```

启动:`uvicorn app.main:app --reload --port 8001`

## 核心概念:启动命令的语义

```
uvicorn app.main:app
        └───┬───┘ └┬┘
         app 包的 main.py 里、名为 app 的变量
```

- `--reload`:改代码自动重启,开发专用(主进程盯文件,子进程跑服务)
- `--port N`:端口被占用时的处理:先查谁占的(`Get-NetTCPConnection -LocalPort N -State Listen`),再决定杀进程还是换端口

## 依赖管理

`requirements.txt` 不是摆设,是**环境配方**——换电脑、建虚拟环境、协作交付,全靠它一键复现:

```
fastapi>=0.110
uvicorn>=0.29
pydantic-settings>=2.0
sqlalchemy>=2.0
pytest>=7.4
httpx>=0.24
```

**铁律:装了必记录。** 装完包不写进配方,环境就复现不了。

## 本课踩过的坑

- 8000 端口被本项目的一个旧实例占用(没开 --reload 跑着旧代码)→ 排查后换 8001
- `--reload` 是多进程结构,停服务要杀整棵树:`taskkill /PID <pid> /T /F`,只杀父进程会留下"孤儿子进程"继续占端口
